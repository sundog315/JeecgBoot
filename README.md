CPE 终端集中管理平台 基于 JeecgBoot 低代码开发平台
===============

当前最新版本： 3.7.2

项目介绍
-----------------------------------
基于JeecgBoot开源低代码平台开发，用于管理基于Openwrt的CPE设备。


开源协议说明
-----------------------------------
此项目基于JeecgBoot开源版本开发，与JeecgBoot开源版本协议相同，底层完全开源可以自主开发，遵循Apache2.0协议，详细见 https://github.com/jeecgboot/JeecgBoot#Apache-2.0-1-ov-file

开源协议中文释意如下：
- 1.JeecgBoot开源版本无任何限制，在遵循本开源协议条款下，允许商用使用，不会造成侵权行为。
- 2.允许基于本平台软件开展业务系统开发。
- 3.在任何情况下，您不得使用本软件开发可能被认为与本软件竞争的软件。
- 4.针对企业用户我们也提供“企业级版本”，详细见 https://jeecg.com/vip
